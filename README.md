// オブジェクト

プリプロ版では、ECS(エンティティ・コンポーネント・システム)っぽい感じの実装をしています。

まず、こんな感じのオブジェクトを作りたい！(マリオとか？ブロックとか)となったら、

とりあえずSystem/Objectファイルにヘッダと.cppファイルを作りましょう。

次に、ヘッダに作りたいオブジェクトを表現するクラスを作ります。

！！！！！！！！！！注意！！！！！！！！！！

必ず、Objectクラスを継承してください！

コンポーネントの機能を使うために必須です！

また、Objectクラスを継承すると、コンストラクタ(生成時の初期化処理)でint型のidを渡す必要があります！

sampleObject.cppなどを参考に、 : Object(ObjectManager::makeId())と書いてください。



更新関数はObjectに用意されているupdate()をオーバーライドして使ってください。





// コンポーネント

コンポーネントについては、オブジェクトのコンストラクタでaddComponent<コンポーネントの型名>(必要な引数)と書くことで

追加できます。

更新関数の中などで必要に応じて追加ということもできなくはないですが、事故の元なので基本はなしとします。

現状、当たり判定(丸、四角、線、点)、座標移動、重力込み座標移動、表示のコンポーネントがあります。

欲しい機能に応じて追加してください。

追加したコンポーネントの機能を使いたい、座標更新をしたい場合はgetComponent<追加したコンポーネントの型名>()で一度取り出してから

使います。

！！！！！！！！！！注意！！！！！！！！！！

必ず、auto 変数名 =  getComponent<>()と書いてから使ってください。

変数に保存しといた方がデバッグが圧倒的にしやすいからです。

また、getComponentで返ってくる値は特殊なポインタのため、

.lock()と書いてからでないと機能が使えません(使いにくい場合は今後修正します)。
